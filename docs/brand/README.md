# Identidade visual do d-BMO

Esta pasta reúne a documentação normativa da identidade visual e do personagem do projeto d-BMO (Dark BMO), aplicada à camada de apresentação (d-BMO Interface).

## Documentos

- [Diretrizes da marca](DBMO_BRAND_GUIDELINES.md): fundamentos, personalidade, símbolo, aplicações e regras de uso.
- [Design tokens](DESIGN_TOKENS.md): cores, tipografia, medidas e tokens iniciais para interfaces.
- [Especificação do personagem](CHARACTER_SPECIFICATION.md): anatomia visual, vistas, expressões e requisitos para modelagem.
- [Diretrizes de interface](UI_GUIDELINES.md): aplicação visual em interface conversacional, terminal e dashboard.

## Estado e autoridade

Esta documentação registra a direção visual aprovada como referência de projeto. A prancha gerada por IA é uma referência conceitual, não um arquivo-fonte vetorial, projeto CAD ou prova de implementação.

Quando os ativos originais forem incorporados ao repositório, devem ser armazenados em `assets/`, com autoria, origem, formato e versão documentados. Não se deve reconstruir ou substituir silenciosamente um ativo aprovado.

## Relação com a arquitetura

A identidade d-BMO se aplica à camada de interação (d-BMO Interface). Não é o núcleo de inteligência. Consulte [ARCHITECTURE.md](../../ARCHITECTURE.md) para as responsabilidades de BMO Brain, Heart, Knowledge e Model Lab.
